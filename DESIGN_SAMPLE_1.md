# Design Sample 1: Athletic Brutalism

## Visual Concept
**Professional, High-Contrast, Bold Typography, Sports-Focused**

### Hero Section
- Full-bleed background: Dark athlete action shot with radial gradient overlay
- Centered headline (Cabinet Grotesk): "Name, Image, Likeness" (2 lines, 96px)
- Subhead: "What you sign now matters for the next four years"
- Two CTAs centered: [Schedule Call] [Learn More]
- Height: 90vh

### Content Architecture
**Split Block Pattern:**
```
[Full-Width Section - Dark Background]
  → Headline (72px, left-aligned)
  → Body copy (18px, max-w-3xl)
  → 3-column stats/features

[Full-Width Image Break]
  → Sports action imagery with overlay text quote

[Split Section - White Background]
  → Left: Large number "01" (240px, maroon)
  → Right: Service description + bullet points

[Repeat pattern with alternating colors]
```

### Key Features
- **Typography Scale:** 96px → 72px → 48px → 18px (clear hierarchy)
- **Color System:** White/Navy/Maroon with high contrast
- **Imagery:** Full-bleed athlete action shots (grayscale with maroon accent)
- **Spacing:** 160px vertical between sections
- **Motion:** Images scale 0.8 → 1.0 on scroll

### Service Pages Layout
1. Hero (full-bleed)
2. Service Overview (split block - text left, stats right)
3. Image Break (full-width athlete)
4. How It Works (numbered timeline - vertical)
5. Case Study Card (wide card with image)
6. CTA Footer (full-width, high contrast)

### Pros
- Very sporty and athletic feel
- High contrast makes everything readable
- Clear information hierarchy
- Professional without being corporate

### Cons
- Could feel too heavy/dark
- Less "innovative" - more traditional bold design
